# Sigmachat v1.5.3

This is a small chatting app I made with Node.js and Socket.io and a bit of WebRTC.

It works (looks best) on PC/laptop, or a suitably sized iPad.

Replit fork link: ➤ <kbd>[**Replit fork link**](https://replit.com/@thatswitchguy/Sigmachat)</kbd>

## Features

- DM (Direct messaging)
- Servers with channels
- Profiles and users
- Image/Video upload
- Fast message updating
- Dark UI (similar to discord)
- Incognito mode
- Video meetings
- /stream for streaming
